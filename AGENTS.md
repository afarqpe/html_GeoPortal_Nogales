## Cursor Cloud specific instructions

This is **GEOPORTAL_NOGALES**, a static web map application for Nogales, Chile, generated by the qgis2web QGIS plugin. It uses OpenLayers (ol.js) with GeoJSON data embedded in JS files.

### Architecture

- Purely static HTML/JS/CSS — no build system, no package manager, no backend.
- All dependencies (OpenLayers, proj4, FontAwesome, etc.) are vendored in `resources/`.
- GIS data layers live in `layers/*.js`; styles in `styles/*.js`.
- Entry point: `qgis2web_2025_12_26-15_34_08_686321/index.html`.

### Running the application

Serve the static site from the `qgis2web_2025_12_26-15_34_08_686321/` directory:

```
cd qgis2web_2025_12_26-15_34_08_686321
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

### Notes

- There are no lint, test, or build steps — the codebase is a pre-built static export.
- External tile services (Google Maps, OpenStreetMap) and the Photon geocoding API are fetched at runtime in the browser; no API keys are required.
- No environment variables or secrets are needed.
